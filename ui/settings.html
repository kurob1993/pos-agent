Pemasangan pertama

  1. Hubungkan monitor kedua ke PC kasir, lalu atur layar ke mode Extend (perluas), bukan Duplicate/Mirror.
  2. Jalankan aplikasi ini. Ikonnya muncul di system tray (dekat jam). Klik kanan ikon untuk Pengaturan, Tampilkan ulang, atau Keluar.
  3. Di tab Pengaturan, pilih monitor dan mode jendela, lalu klik Simpan. Bawaannya layar penuh di monitor kedua.
  4. Buka halaman kasir (POS) di browser dan buka layar pelanggan dari sana. Halaman POS terhubung ke ws:// dan mengirim alamat layar pelanggan.
  5. Pertama kali, muncul dialog izin untuk situs POS. Pilih Izinkan. Izin tersimpan, jadi tidak ditanya lagi untuk situs yang sama.
  6. Opsional: di tab Pengaturan bagian Suara, klik Unduh suara natural (±139 MB, butuh internet sekali saja). Pilih Kecepatan suara natural, klik Simpan, lalu coba dengan Test suara (boleh isi teks sendiri).

Pemakaian sehari-hari

  • Layar pelanggan tampil di monitor yang dipilih setiap kali POS mengirim alamatnya.
  • Setiap POS melaporkan pembayaran sukses, aplikasi memutar denting koin lalu suara "Pembayaran berhasil …" lewat speaker PC.
  • Saat PC menyala, aplikasi menunggu monitor sesuai Pengaturan (sampai ±30 detik). Jika monitor itu tidak tersambung, layar pelanggan tidak ditampilkan.
  • Jika monitornya tersambung, muncul dialog Tampilkan layar pelanggan di mana?. Pilih monitor lalu Tampilkan, atau Jangan tampilkan. Tanpa pilihan, dialog memilih otomatis setelah 15 detik. Monitor yang dipilih di dialog ikut tersimpan di Pengaturan.
  • Alamat terakhir dari POS disimpan di config.json (folder konfigurasi aplikasi) dan dihapus saat aplikasi ditutup lewat Keluar atau saat POS mengirim close.
  • Jika belum ada alamat atau situs POS tidak bisa dijangkau, layar pelanggan menampilkan halaman bawaan "Selamat datang" sampai kasir membuka POS.
  • Jendela tertutup, berpindah, atau tadi memilih Jangan tampilkan? Klik kanan ikon tray lalu pilih Tampilkan ulang.
  • Perubahan di tab Pengaturan berlaku setelah klik Simpan, tanpa memuat ulang halaman POS.
  • Menutup jendela Pengaturan tidak menghentikan aplikasi. Untuk berhenti, pilih Keluar di menu tray.

Jika bermasalah

  • Monitor kedua tidak terdeteksi: periksa kabel dan pastikan layar dalam mode Extend, atau pilih monitor secara manual di Pengaturan.
  • Layar pelanggan tidak muncul saat PC menyala: monitor di Pengaturan tidak tersambung saat login, atau dialog dijawab Jangan tampilkan. Pilih Tampilkan ulang di menu tray.
  • Layar tampil di monitor yang salah: pilih monitornya di Pengaturan, bukan "Otomatis", atau pilih monitor yang benar di dialog saat PC menyala.
  • Yang tampil halaman "Selamat datang": situs POS belum bisa dijangkau atau belum pernah mengirim alamat. Buka halaman kasir; layar pelanggan berpindah begitu POS mengirim open.
  • Tidak bisa memakai host:port: port sedang dipakai program lain. Ganti port di sini dan di halaman POS.
  • POS tidak tersambung: port di aplikasi ini dan di halaman POS harus sama (sekarang ).
  • "Situs ini ditolak": Anda memilih Tolak pada dialog izin. Pilihan itu tidak disimpan, jadi kirim ulang dari POS dan pilih Izinkan.
  • Tidak ada suara pengumuman: periksa volume speaker. Suara natural butuh model Supertonic di folder konfigurasi aplikasi; tanpa model, suara mengikuti TTS OS (Windows perlu voice Bahasa Indonesia).
  • Suara terlambat terdengar: pilih Cepat di Kecepatan suara natural lalu Simpan. Pengumuman pertama setelah aplikasi dibuka bisa sedikit lebih lama karena model masih dimuat.
  • Ikon tray tidak terlihat (Linux GNOME): pasang ekstensi "AppIndicator and KStatusNotifierItem Support".

Untuk pengembang POS

Kirim pesan JSON lewat WebSocket. Setiap pesan dibalas satu JSON berisi ok; jika gagal, ada juga error.

  • ping: cek aplikasi. Balasan memuat version dan monitor (apakah monitor tujuan terdeteksi).
  • open: tampilkan layar pelanggan. url harus berasal dari situs (origin) yang sama dengan halaman pengirim. Situs baru memicu dialog izin.
  • close: tutup layar pelanggan. Hanya untuk situs yang sudah diizinkan, dan tidak memicu dialog.
  • speak: umumkan pembayaran berhasil lewat speaker. method: cash/edc/qris, amount angka positif. Diputar dengan denting koin di depan; ok dikirim tanpa menunggu suara selesai. Beberapa pengumuman diantrekan, tidak saling tumpang tindih.
  • say: ucapkan teks bebas lewat speaker. text wajib, maksimal 500 karakter; coin opsional (true = denting koin di depan, bawaan false). Hanya untuk situs yang sudah diizinkan.
{"type":"ping"}
→ {"ok":true,"version":"0.7.0","monitor":true}

{"type":"open","url":"https://pos.contoh.com/layar-pelanggan"}
→ {"ok":true}

{"type":"close"}
→ {"ok":true}

{"type":"speak","method":"qris","amount":50000}
→ {"ok":true}

{"type":"say","text":"Silakan ambil struk Anda.","coin":false}
→ {"ok":true}

// contoh gagal
→ {"ok":false,"error":"Alamat tidak berasal dari situs POS ini"}

close juga melupakan alamat terakhir, jadi saat login berikutnya layar pelanggan menampilkan halaman bawaan sampai POS mengirim open lagi.

Mode tanpa UI: jalankan pos-agent --headless dari terminal Linux atau cmd Windows. Hanya WebSocket (ping, speak, say) dan suara yang berjalan; tidak ada jendela, tray, maupun layar pelanggan, dan hanya situs yang sudah diizinkan yang dilayani. Jangan jalankan bersamaan dengan mode biasa karena memakai port yang sama.

Kata QRIS diucapkan "keris". Suara natural Supertonic 3 Bahasa Indonesia dipakai bila folder tts-model ada di folder konfigurasi aplikasi; tanpa itu suara mengikuti TTS OS. Model bisa diunduh lewat tombol di tab Pengaturan.

First-time setup

  1. Connect the second monitor to the cashier PC and set the displays to Extend mode, not Duplicate/Mirror.
  2. Start this app. Its icon appears in the system tray (near the clock). Right-click the icon for Settings, Show again, or Quit.
  3. In the Settings tab, choose the monitor and window mode, then click Save. The default is fullscreen on the second monitor.
  4. Open the cashier (POS) page in a browser and open the customer display from there. The POS page connects to ws:// and sends the customer display address.
  5. The first time, a permission dialog appears for the POS site. Choose Allow. The choice is saved, so you won't be asked again for the same site.
  6. Optional: in the Settings tab, Voice section, click Download natural voice (±139 MB, needs the internet once). Choose the Natural voice speed, click Save, then try it with Test voice (you can type your own text).

Day-to-day use

  • The customer display shows on the chosen monitor whenever the POS sends its address.
  • Whenever the POS reports a successful payment, the app plays a coin chime followed by a "Payment successful …" announcement through the PC speakers.
  • When the PC starts, the app waits for the monitor set in Settings (up to ~30 seconds). If that monitor is not connected, the customer display is not shown.
  • If the monitor is connected, a Where to show the customer display? dialog appears. Pick a monitor and click Show, or Don't show. Without a choice, it picks automatically after 15 seconds. The monitor picked in the dialog is also saved in Settings.
  • The last address from the POS is saved in config.json (the app config folder) and cleared when the app is closed via Quit or when the POS sends close.
  • If there is no address yet or the POS site cannot be reached, the customer display shows the default "Welcome" page until the cashier opens the POS.
  • Window closed, moved, or you chose Don't show? Right-click the tray icon and choose Show again.
  • Changes in the Settings tab apply after clicking Save, without reloading the POS page.
  • Closing the Settings window does not stop the app. To stop it, choose Quit in the tray menu.

Troubleshooting

  • Second monitor not detected: check the cable and that the displays are in Extend mode, or pick the monitor manually in Settings.
  • Customer display does not appear when the PC starts: the monitor set in Settings was not connected at login, or the dialog was answered with Don't show. Choose Show again in the tray menu.
  • Display shows on the wrong monitor: select the monitor in Settings instead of "Automatic", or pick the right monitor in the dialog when the PC starts.
  • The "Welcome" page is shown: the POS site cannot be reached yet or has never sent an address. Open the cashier page; the display switches as soon as the POS sends open.
  • Cannot use host:port: another program is using the port. Change the port here and on the POS page.
  • POS cannot connect: the port in this app and in the POS page must match (currently ).
  • "This site was denied": you chose Deny in the permission dialog. That choice is not saved, so send it again from the POS and choose Allow.
  • No announcement sound: check the speaker volume. The natural voice needs the Supertonic model in the app's config folder; without it, the OS TTS engine is used (needs an Indonesian voice on Windows).
  • Voice is heard too late: choose Fast in Natural voice speed and click Save. The first announcement after the app starts can take a little longer while the model loads.
  • Tray icon not visible (Linux GNOME): install the "AppIndicator and KStatusNotifierItem Support" extension.

For POS developers

Send JSON messages over the WebSocket. Each message gets one JSON reply containing ok; on failure it also has error.

  • ping: check the app. The reply includes version and monitor (whether the target monitor is detected).
  • open: show the customer display. url must come from the same site (origin) as the sending page. A new site triggers the permission dialog.
  • close: close the customer display. Only for already-allowed sites, and never shows a dialog.
  • speak: announce a successful payment through the speakers. method: cash/edc/qris, amount a positive number. Played with a leading coin chime; ok is sent without waiting for the speech to finish. Several announcements are queued, never overlapping.
  • say: speak any text through the speakers. text is required, at most 500 characters; coin is optional (true = leading coin chime, default false). Only for already-allowed sites.
{"type":"ping"}
→ {"ok":true,"version":"0.7.0","monitor":true}

{"type":"open","url":"https://pos.example.com/customer-display"}
→ {"ok":true}

{"type":"close"}
→ {"ok":true}

{"type":"speak","method":"qris","amount":50000}
→ {"ok":true}

{"type":"say","text":"Please take your receipt.","coin":false}
→ {"ok":true}

// failure example
→ {"ok":false,"error":"Address does not belong to this POS site"}

close also forgets the last address, so at the next login the customer display shows the default page until the POS sends open again.

Headless mode: run pos-agent --headless from a Linux terminal or Windows cmd. Only the WebSocket (ping, speak, say) and voice run; there are no windows, tray, or customer display, and only already-allowed sites are served. Do not run it alongside normal mode since both use the same port.

The word QRIS is pronounced like "keris" (the traditional dagger). The natural Supertonic 3 Indonesian voice is used when the tts-model folder exists in the app config folder; otherwise the OS TTS engine is used. The model can be downloaded via the button in the Settings tab.
